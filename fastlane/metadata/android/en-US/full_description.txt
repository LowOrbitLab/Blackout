Blackout keeps keys on your device and signs cryptocurrency transactions offline. Exchange account information and signing requests with supported companion wallets using QR codes.

Create or restore wallets, inspect transaction details, and return signed responses without broadcasting from Blackout.

Blackout is an independent project based on AirGap Vault. It uses a separate application identity and data space, and can be installed alongside AirGap Vault. Existing wallets must be restored explicitly. AirGap Wallet, MetaMask, and other companion products belong to their respective providers.

Source code and documentation: https://github.com/LowOrbitLab/Blackout
